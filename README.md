# HealthConnect Rwanda — PM Transformation Programme

**AnalystLab Africa Experience Lab | Week 6 Assignment**

## Project Overview
This repository contains the complete Project Management deliverable suite for the **HealthConnect Rwanda Healthcare Analytics and AI Transformation Programme**. 

The project is a proposed 24-week enterprise initiative to integrate seven disconnected healthcare systems (EMR, HIS, LIS, Pharmacy, Billing, Insurance, Feedback) into a unified analytics platform with governed AI capabilities.

## Deliverables Included
1. **Final Report (Word):** Full 20-section PM report including Business Case, Charter, WBS, Risk Register, and Responsible AI framework.
2. **Control Workbook (Excel):** A 23-sheet PMO workbook featuring live formulas, a Gantt chart, a 25-risk register, a budget tracker, and an interactive dashboard.
3. **Executive Presentation (PowerPoint):** A 14-slide summary deck designed for Board/SteerCo review.

## Integrity & Standards
* **Timelines:** Two distinct timelines are used. **Timeline A** (7 days) represents the internship assignment deadline. **Timeline B** (24 weeks) represents the proposed implementation schedule.
* **Data Integrity:** All costs, dates, and metrics are labelled as **PROPOSED** or **TBC**. No actual deployment, financial approvals, or benefits realisation are claimed. Cross-track dependencies are marked as "Awaiting input."
* **Methodology:** Blends PMBOK-aligned governance with Agile (Scrum) delivery for the build phase.
